# CrisisMate API & Integration Contracts

This document defines the service interfaces provided by **Member 3 (Firebase Backend)** for use by Member 1 (AI Engine) and Member 2 (Frontend).

---

## 1. Firebase Authentication Service (`@/services/firebase/auth`)

### `signInWithGoogle()`
Opens Google Sign-In popup and syncs/creates user profile in Firestore `users/{uid}`.
- **Returns**: `Promise<{ user: User, profile: UserProfile }>`

```typescript
import { signInWithGoogle } from '@/services/firebase/auth';

const { user, profile } = await signInWithGoogle();
```

### `signOutUser()`
Signs out currently logged in user.
- **Returns**: `Promise<void>`

### `getCurrentUser()`
Synchronously returns current Auth user object or `null`.
- **Returns**: `User | null`

### `onAuthStateChange(callback)`
Registers a listener for authentication state changes.
- **Returns**: Unsubscribe function `() => void`

---

## 2. User Profile Service (`@/services/firebase/userService`)

### `getUserProfile(uid: string)`
Retrieves profile document from Firestore.
- **Returns**: `Promise<UserProfile | null>`

### `createOrUpdateUserProfile(userData)`
Creates or merges user profile properties in `users/{uid}`.
- **Returns**: `Promise<UserProfile>`

---

## 3. Trusted Contact Service (`@/services/firebase/contactService`)

### `addTrustedContact(userId: string, contactData: CreateTrustedContactInput)`
Adds a new trusted contact document under `users/{userId}/trustedContacts/{contactId}`.
- **Returns**: `Promise<TrustedContact>`

### `getTrustedContacts(userId: string)`
Fetches all trusted contacts for a user.
- **Returns**: `Promise<TrustedContact[]>`

### `updateTrustedContact(userId: string, contactId: string, updateData)`
Updates existing contact.
- **Returns**: `Promise<TrustedContact>`

### `deleteTrustedContact(userId: string, contactId: string)`
Deletes contact document.
- **Returns**: `Promise<void>`

---

## 4. Emergency History Service (`@/services/firebase/emergencyService`)

### `saveEmergencySession(userId: string, sessionData: CreateEmergencySessionInput)`
Saves an emergency decision engine analysis result generated by Member 1 (AI) to Firestore.
- **Returns**: `Promise<EmergencySession>`

### `getEmergencyHistory(userId: string)`
Retrieves all historical emergency sessions for a user, ordered newest first.
- **Returns**: `Promise<EmergencySession[]>`

### `getEmergencySession(userId: string, sessionId: string)`
Retrieves single emergency session document.
- **Returns**: `Promise<EmergencySession | null>`
